# Argus REC: бесплатный запуск по ссылке (Render)

## Что это даст
- Приложение работает в облаке 24/7 (пока сервис не "уснул" на free-тарифе).
- Открывается по одной HTTPS-ссылке в любом браузере (iPhone, Android, Mac, Windows).
- Твой компьютер не нужно держать включенным.

## Важно про free-тариф
- Первый запуск после "сна" может занять 30-90 секунд.
- Файлы записей в бесплатном веб-сервисе могут не храниться вечно (эфемерное хранилище).
- Для стабильной постоянной базы файлов потом нужен платный диск/хранилище.

## Запуск (5 минут)
1. Зайди на https://render.com и войди через GitHub.
2. Нажми `New +` -> `Blueprint`.
3. Выбери репозиторий `LBforeal/argus-rec`.
4. Нажми `Apply` (Render сам возьмет настройки из `render.yaml`).
5. Дождись статуса `Live`.
6. Открой URL вида `https://argus-rec.onrender.com`.

## Как проверять
- Главный экран: загрузка файла / список.
- Детальный экран: 4 вкладки.
- Микрофон на iPhone: только в Safari и после разрешения доступа.

## Если запись не стартует
- Проверь, что открыт именно `https://...onrender.com` (не http).
- Проверь разрешение микрофона в Safari:
  `Настройки -> Safari -> Микрофон -> Разрешить`.
